# Campus Lost & Found System

## 📌 Project Overview

Campus Lost & Found System is a web-based application designed to help students report, search, and manage lost and found items within a college campus.

Instead of depending on WhatsApp groups or verbal communication, students can use one centralized platform to report lost items, report found items, search for items, and submit claim requests.

## 🎯 Objectives

- Provide a centralized platform for lost and found items
- Allow students to report lost items
- Allow students to report found items
- Make items easy to search and filter
- Allow students to submit claim requests
- Allow students to track their claim requests

## ✨ Features

- Student Registration
- Student Login
- Dashboard
- Report Lost Item
- Report Found Item
- View All Lost and Found Items
- Search Items
- Filter Items by Lost/Found Type
- Search Items by Location
- Submit Claim Request
- View Claim Requests
- Claim Status

## 🛠️ Technologies Used

- Flask
- HTML
- CSS
- SQLite
- Jinja2
